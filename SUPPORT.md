# Getting help

We are a small team and we read everything. Here is the fastest route for each need.

| I want to… | Go here |
|---|---|
| Learn how to set AuthNest up | [Get started in 10 minutes](docs/GETTING_STARTED.md) and the [documentation](https://authnest.org/docs/introduction) |
| Ask a question or get unstuck | [Open a question](../../issues/new/choose) |
| Report something that is broken | [Open a bug report](../../issues/new/choose) |
| Suggest a feature | [Open a feature request](../../issues/new/choose) |
| Talk to a person about my account or billing | [authnest.org/contact-us](https://authnest.org/contact-us) |
| Report a security problem | Please do **not** open a public issue. See [SECURITY.md](SECURITY.md) |
| See if the service is having problems | [authnest.org/status](https://authnest.org/status) |

**Never post secrets in an issue.** That includes API secret keys, passwords, tokens and `.env` files. If you pasted
one by mistake, rotate it straight away in your dashboard and edit the issue.
